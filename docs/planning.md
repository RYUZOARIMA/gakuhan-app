# 学販アプリ 企画メモ

学校でのジャージ・帽子・鞄などの販売品について、注文受付から発注までを管理するアプリ。

## 経緯・方針

- 保護者/生徒からの注文を受け付け、学校側が集計して仕入先に発注する、という2段階のフローがコア。
- 複数校対応は「商品ラインナップ・価格・発注先が学校ごとに違う」「権限管理」など分岐が増えてミスの温床になるため見送り、**まず1校専用のシンプルな内部管理ツール**として作る。
- 決済はオンライン決済を組み込まず、銀行振込 or 現金集金など既存の方法に任せる（個人情報保護・決済対応まわりの複雑化を避けるため）。オンライン決済が必要になった場合は、道場サイト（`my-new-app-test`）で導入済みのStripe連携を流用できる。
- 道場サイトとは業務ドメインが別なので、プロジェクトフォルダ・Gitリポジトリを分離。`GitHub/gakuhan-app` として独立に作成済み（Next.js 16.3.4 / React 19 / TypeScript / Tailwind CSS、道場サイトと同構成）。

## 機能一覧（MVP）

1. **商品マスタ** — ジャージ・帽子・鞄などの品目、サイズ、単価、仕入先を登録
2. **注文受付** — 生徒/クラスごとに商品・サイズ・数量を入力（締切のある「注文期間」単位で管理）
3. **注文集計** — 商品×サイズ別の必要数を自動集計
4. **発注書生成** — 仕入先ごとに発注書（PDF/CSV）を出力
5. **入荷・配布管理** — 入荷記録と生徒への配布チェック
6. **支払い管理** — 銀行振込確認 or 現金集金のチェックリスト

## データモデル（案）

- `Product`（商品名・カテゴリ・単価・仕入先）
- `ProductVariant`（商品×サイズ）
- `Supplier`（仕入先）
- `OrderWindow`（注文期間・締切・ステータス）
- `Order`（生徒名・クラス・注文期間・ステータス）
- `OrderItem`（注文明細：バリアント・数量）
- `PurchaseOrder`（仕入先向け発注・注文期間）
- `PurchaseOrderItem`（発注明細：バリアント・数量）
